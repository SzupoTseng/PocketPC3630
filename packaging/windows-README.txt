PocketPC3630 for Windows
========================

Play Pocket PC games and apps (ARM, MIPS and SH3 builds) on Windows.
https://github.com/SzupoTseng/PocketPC3630

Start
-----
1. Unzip this folder anywhere, for example to your Documents.
2. Double-click PocketPC3630.exe.
3. Click "Import game" and choose a Pocket PC .zip, .cab or setup .exe.
   You do not need to unzip it or pick the right processor build.
4. Click the game to play.

Controls
--------
Mouse click = stylus.  Arrow keys = D-pad.  Enter = action key.  Esc = back.
Each game's "..." menu can download, import or reset its save.
Save files work in the browser and Android versions too.

Free games to try
-----------------
https://szupotseng.github.io/PocketPC3630/#free

Command line
------------
pockethle.exe play MyGame.zip      import and run a package
pockethle.exe --help               everything else

PocketPC3630 contains no games and no Microsoft files.

PocketPC3630 Windows 版
=======================

在 Windows 上玩 Pocket PC 的遊戲與軟體（ARM、MIPS、SH3 版本都可以）。

開始
----
1. 把這個資料夾解壓縮到任何地方，例如「文件」。
2. 按兩下 PocketPC3630.exe。
3. 按「Import game」，選擇 Pocket PC 的 .zip、.cab 或安裝程式 .exe。
   不用先解壓縮，也不用挑處理器版本。
4. 點遊戲就能開始。

操作
----
滑鼠點擊＝觸控筆。方向鍵＝方向鍵。Enter＝動作鍵。Esc＝返回。
每個遊戲的「...」選單可以下載、匯入或重置存檔，
存檔和網頁版、Android 版通用。

--------
https://szupotseng.github.io/PocketPC3630/#free

PocketPC3630 不附任何遊戲或微軟檔案，請只使用你合法取得的軟體。
