# 程式圖書館與個人程式庫 UI 規劃

更新：2026-11-08。對應 [ui_TODO](../ui_TODO.md) 的 UI-14、UI-15、UI-17、UI-21～25；操作定義沿用 [七種操作方案與測試計畫](INPUT_PROFILES_TEST_PLAN.md)，不另建一套按鍵設定。

本文件定義完整設計。2026-11-08 已實作 Web 首版介紹、操作預覽、操作需求篩選及各軟體的 Web 按鍵盤／鍵盤顯示設定，驗證範圍見 [實測紀錄](../proof/library-ui/README.md)。Windows／Android 原生介面及共用 Rust 配置模型尚未串接；七種方案中的裝置面板僅提供明確標示的介紹預覽，不可套用。現有 Web 有公開「程式圖書館」與「我的遊戲庫」兩區；其用途及資料狀態必須清楚區分。

## 圖書館應回答的問題

每套軟體的介紹要讓使用者在啟動前知道：這是什麼、畫面長什麼樣、怎麼操作、需要哪些按鈕、這個平台測到哪裡，以及如何開始。遊戲、閱讀器、計算機、編輯器都適用，不只介紹遊戲內容或列出 CPU 名稱。

| 區域 | 用途 | 主要動作 | 個人資料 |
| --- | --- | --- | --- |
| 程式圖書館 | 探索軟體、閱讀介紹／操作教學、查看相容性 | 查看介紹；有可用來源時取得／加入，否則匯入本機檔案 | 不把目錄推薦當作使用者已選方案 |
| 我的程式庫（目前「我的遊戲庫」） | 管理已匯入的實際軟體版本、操作配置及進度 | 開始程式、操作設定、備份／還原 | 顯示目前套用的方案與此軟體覆寫 |

公開目錄的版本與本機實際 EXE 不一定相同。以穩定軟體 id 加版本／架構／檔案證據關聯；無法確定時顯示「尚未匹配此版本」，不可直接沿用其他版本的操作驗證。

## 1. 圖書館首頁與卡片

首頁先提供名稱／別名搜尋、遊戲／應用分類，再提供操作需求篩選：觸控筆、方向鍵、文字鍵盤、硬體按鈕、滑鼠／手把。操作需求是軟體需要的輸入，與「OP-01～07 操作方案」分開，避免把手把誤當成唯一方案。

卡片只放必要資訊，詳細資料展開：

| 卡片欄位 | 呈現方式 |
| --- | --- |
| 名稱／副標題 | 原名加可辨識別名；EQ 三部能一眼區分，不截斷成相同前綴 |
| 圖像 | 實際畫面優先，缺少時用圖示或明確的無截圖占位；模擬控制盤預覽不得當作遊戲實測截圖 |
| 一句介紹 | 類型與用途，例如角色扮演、閱讀、計算；不塞入診斷參數 |
| 操作摘要 | 最多兩個主要標籤，如「觸控筆」「可用硬體鍵」，另有「查看操作」入口 |
| 測試摘要 | 顯示目前平台／指定版本的驗證範圍；不能只用一個綠色標籤混合啟動與操作完整度 |
| 主動作 | 未安裝：查看介紹／取得或匯入；已安裝：開啟本機版本；不可啟動：查看原因 |

不把七個方案全部塞進卡片，也不讓下載按鈕、開始按鈕與設定按鈕互相重疊。手機用可展開區塊呈現操作介紹；Windows／寬螢幕 Web 可用詳細側欄，保留搜尋及捲動位置。

## 2. 每套軟體的介紹頁

內容順序依使用流程排列：

1. **軟體簡介與版本**：原名、別名、用途、指定版本／架構、來源說明。
2. **畫面與 UI 導覽**：實際截圖加編號說明，例如遊戲區、狀態列、選單、背包或翻頁區。只描述該版本已確認的介面，不猜按鈕功能。
3. **如何開始**：首次開啟、選單／角色／文件選擇、進入主畫面的必要步驟。
4. **操作方式**：推薦方案、可選替代方案、畫面觸控／拖曳、必要硬體鍵、鍵盤／手把對照；功能尚未實作時明確標示。
5. **保存與退出**：此軟體如何寫出進度／文件、何時可備份、返回程式庫的影響；不把進度 ZIP 描述為即時存檔。
6. **驗證與限制**：分平台／核心／版本呈現，附測試日期與可理解的限制；技術日誌另展開。

軟體自己的 UI 與模擬器的 UI 要明確標註。例如「遊戲右上角 Options」與「模擬器操作設定」用不同名稱，避免教學帶使用者點錯入口。

介紹範例（編排示意，非新增驗收結果）：

| 軟體 | 操作介紹重點 | 推薦／替代方案 | 保存說明 |
| --- | --- | --- | --- |
| EQ EP1／EP2／EP3，各自一筆 | 點地移動、選角、狀態區、背包／地圖及遊戲 Options；三部差異分開說明 | 觸控筆優先；可選精簡快捷列、完整 Pocket PC、自訂或裝置面板 | 先完成遊戲內保存流程，再備份進度；註冊 GUI 與世界流程分開標示 |
| JumpyBall | 方向與動作、畫面方向、分數區；先確認該版實際動作 | 方向＋動作鍵；可選手把、完整 Pocket PC 或裝置面板 | 依已確認的分數／設定保存能力說明 |
| 閱讀器 | 文件選單、閱讀區、翻頁、搜尋及書籤；指定版本未啟動時標示阻塞 | 文字／閱讀；可選觸控、硬體翻頁鍵、手把 | 區分文件、閱讀位置與書籤，未驗證項不保證保存 |
| 計算機／編輯器 | 輸入區、功能頁、退格／游標與焦點 | 觸控筆或文字模式；可選滑鼠鍵盤 | 只介紹該版實際存在的保存／重讀功能 |

## 3. 操作方案介紹與互動預覽

每套介紹頁有「查看操作」入口，列出 OP-01～07，但只將已匹配該版本的方案標為推薦。使用者能查看全部可用方案並覆寫；篩選條件不能偷偷改變目前選擇。

- 預覽顯示螢幕區、按鈕位置、每個按鈕送出的動作與實際主機綁定；點擊預覽只亮燈／顯示名稱，不向正在執行的客體送事件。
- 可選直／橫向與左右手，預覽必要資訊是否被遮擋；未實作的編輯能力不顯示成已可使用。
- Device Emulator 裝置面板另列機型／OS／skin 來源。標明中央鍵、App 鍵與觸控區；不能拿遊戲 A／B／C 名稱代替已驗證的硬體按鈕語意。
- 展開「鍵盤／手把對照」時顯示目前裝置的有效綁定。未接手把、未支援相對滑鼠或 IME 時，說明能力狀態並提供其他操作方式。
- 「套用至此軟體」只更改操作配置；不立即啟動、不改全域、不重裝。公開目錄尚未安裝時可先預覽；明確選擇的方案可作為待套用設定，在成功匹配本機版本後套用，不把推薦自動變成覆寫。
- 「恢復繼承設定」與「自訂」維持可見；預覽關閉／取消時不寫入設定。

依賴 UI-11 的共用設定與 UI-19／20 的裝置語意；資料尚未齊備時顯示「操作資訊待補」，仍保留手動選擇，不偽造推薦。

## 4. 個人程式庫的操作入口

卡片顯示目前方案，例如「觸控筆優先・此軟體自訂」或「完整 Pocket PC・繼承全域」。主動作維持開始程式；更多選單提供操作設定、軟體介紹、一般設定、備份／還原及移除。常用設定不要求先啟動程式。

操作設定共用同一張配置頁，來源可以是公開介紹、個人程式庫或遊戲中選單。只顯示一次目前有效配置，避免三個入口各存不同副本。啟動時使用有效方案；之後切換的釋放／保存流程沿用 CT-05。

空庫顯示匯入與探索圖書館入口；無搜尋結果提供清除篩選；缺操作資料提供通用方案；載入／匯入中顯示進度並防止重複動作。下載或匯入失敗不先把程式標成已安裝。

## 5. 相容性與操作狀態

狀態至少分開：**素材／安裝、啟動／畫面、操作驗證、進度保存**。必要時另列音訊，不以有聲音推論控制可用。「能啟動」不寫成「完整可玩」；範例截圖不能作為目前平台已測證據。

操作驗證逐項顯示未測、待實作、通過、失敗、阻塞、不適用，沿用輸入測試計畫的定義。測試證據需匹配版本與平台；公開目錄、APK、WASM 的資料不同步時，保留日期／版本差異，不把舊結果蓋成最新。

共用 catalog 資料提供軟體簡介、UI 導覽、操作需求、推薦方案及版本化驗證摘要；個人設定只保存所選方案與覆寫。原始測試紀錄可從摘要追溯，不能由介紹文案自行產生「已通過」。

## 逐項 UI 測試計畫（完整驗收規格）

Web 首版只完成實測紀錄列出的部分步驟；下表還包括尚未提供的跨平台、匹配、共用配置與輔助工具驗收，不能整列推定通過。

| 案例 | 步驟 | 通過條件 |
| --- | --- | --- |
| LIB-01 探索與返回 | 搜尋 EQ／閱讀器，選操作需求篩選，開介紹再返回 | 結果正確、條件與捲動保留；無結果可清除篩選 |
| LIB-02 每套介紹 | 分別檢查 EQ 三部、JumpyBall、閱讀器與計算機／編輯器 | 簡介、UI 導覽、操作、保存與驗證區齊備；缺資料明示，EQ 三部可區分 |
| LIB-03 操作預覽 | OP-01～07 逐一預覽、切方向、點預覽按鍵、取消 | 顯示正確控制且不向客體送事件；取消不保存，未支援項不假裝可用 |
| LIB-04 個別套用 | A 套用一個方案，B 套用另一個，再由三個入口查看；重啟 app／頁面 | 目前配置一致且各軟體獨立；恢復繼承不影響全域／B，進度不變 |
| LIB-05 未安裝到安裝 | 目錄預覽／明確選方案，再成功匯入；另測錯誤版本及匯入失敗 | 僅匹配成功才套用待選配置；失敗不顯示已安裝，錯版不承接驗證狀態 |
| LIB-06 驗證標籤 | 以未測、僅啟動、操作失敗、進度通過等測試資料，切換平台／版本 | 各狀態獨立，舊版本／其他核心證據不冒充目前已測 |
| LIB-07 裝置面板介紹 | 開 OP-07，比對來源標示、App 鍵、中央鍵、viewport，再進實際操作設定 | 語意與 UI-20 已驗證資料一致；無參照明示未驗證，不把面板亮燈算實測 |
| LIB-08 響應式與可存取性 | 手機直橫向、桌面窄窗、文字放大；鍵盤／螢幕閱讀器走搜尋、介紹、方案及返回 | 文字不遮擋主要操作，焦點可預期、狀態可讀，卡片按鈕不互相觸發 |
| LIB-09 缺資料與錯誤 | 無截圖、無操作說明、目錄下載失敗、離線、重複點取得／開始 | 有占位／可重試或可用的本機資料；不偽造畫面／推薦、不重複安裝或啟動 |
| LIB-10 設定與進度安全 | 在已有進度的本機版本改方案、重新匹配目錄資料、匯入更新、備份還原 | 操作介紹更新不覆寫個人設定或進度；更新／備份邊界遵守 UI-01／02，未擴充格式不假稱搬移配置 |

桌面 Web、觸控 Web、Windows egui、Android 各記錄結果與產物／版本；Android 不同核心的實際啟動／操作結果分開。只在 Web 存在的公開目錄流程，其他前端若尚未提供對應入口則標待實作；不把靜態介紹頁通過當作原生 UI 已完成。

實作順序：先有共用軟體操作資料及驗證摘要 → 卡片／介紹頁 → 方案預覽與本機配置入口 → 平台串接 → LIB-01～10 與對應 APP 案例。純介紹內容可先完成；套用及啟動能力必須等實際配置支援，不能先畫出無效按鈕。
