遊戲包格式

直接匯入從網路下載的檔案即可。看不懂的檔案，模擬器會依知識庫往裡面找出遊戲，絕不會執行下載的程式。

可以匯入

  • Pocket PC 的 .cab
  • 最上層放一個 .cab 的 .zip，可以附加其他檔案（例如 mfcce300.dll）
  • 遊戲安裝後資料夾的 .zip，例如 quake/PocketQuake.exe
  • ARM 版的 .exe、.rar
  • 桌面安裝程式（setup.exe）或每種處理器各一個 CAB 的下載檔：會自動挑出 ARM 版

遊戲需要的系統檔案

使用 MFC 的遊戲需要 Pocket PC 內建的 mfcce300.dll（有些還需要 olece300.dll），模擬器不附帶。請把你自己裝置上的副本放進 .zip，和 .cab 放在同一層。缺少時，開始遊戲前會提示。

無法匯入

  • .NET Compact Framework 程式
  • 使用浮點指令的 SH4 程式，以及 x86 版本
  • 桌面版 Windows 遊戲與它的 data1.cab

存檔

存檔 .zip 包含遊戲的 saves/ 資料夾與 pockethle-registry.dat，Windows、Android 與網頁版通用。
