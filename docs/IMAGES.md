# Where the library's pictures come from

The software library on the website shows a picture on every card. Each one
comes from one of these places, in this order of preference:

| Kind | Source | How many |
|---|---|---:|
| Box cover or screenshot | The archive.org item the download came from (its cover, box or front image first, then screenshots, then the item's own thumbnail) | most |
| Box cover | Scans of retail boxes in the maintainer's own Pocket PC disc collection | 21 |
| Screenshot | Taken by us, of the program running in PocketPC3630, kept only when it shows the program | many of the programs that run |
| Program icon | Read from the program's own executable inside the download (PE resources; nothing is run) | 216 |
| Category drawing | Drawn for this project | the rest |

Every picture was checked by eye. Plain disc labels, manual pages and scans
that show registration codes or serial numbers were left out. Versions of the
same program share one picture.

## Rights

The box art, screenshots and icons belong to the programs' publishers. They
are shown at small size, one per program, to identify the program in a
preservation catalogue; the library does not offer the programs themselves
for download except where the archive.org item is freely available. If you
hold the rights to a picture and want it removed, open an issue naming the
program and it will be taken down.

The category drawings, the device artwork and the site's own icons are part
of this project and share its license.
