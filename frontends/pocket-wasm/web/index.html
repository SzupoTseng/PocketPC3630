新手教學：三步驟開始玩

第一次用？照著做，五分鐘內就能玩到第一個遊戲。

取得遊戲包

從下方的「Pocket PC 程式圖書館」挑一個標著「可直接玩」的程式，按「下載並開始」就好。自己的遊戲包通常是 .zip、.cab 或安裝程式 .exe，不用解壓縮，也不用挑處理器版本。

匯入

按上方的「匯入遊戲」，選剛下載的檔案。模擬器會自動拆開安裝程式、找出遊戲、挑出適合的版本，完成後出現在「我的遊戲庫」。

下載的程式絕不會被執行，只會被拆開檢查。看不懂的檔案會告訴你原因與下一步。

開始玩

  • 點遊戲名稱開始；按 ‹ 遊戲庫 回來
  • 滑鼠點擊＝觸控筆
  • ↑↓←→ 方向、Enter 動作鍵、Esc 返回
  • 畫面下方有方向鍵圓盤、軟鍵與 A／B／C 按鈕，滑鼠或手指都能按
  • 進度自動保存；「⋯」選單可下載、匯入或重置存檔
  • 畫面是躺著的？按上方「旋轉畫面」，當年的橫向遊戲要把機器轉過來玩

遊戲說缺少 MFC

有些程式需要 Pocket PC 內建的 mfcce300.dll。遊戲畫面上方會出現「自動取得 MFC 並重新開始」，按下去就好：本站會從 archive.org 下載微軟當年免費提供的 Pocket PC 2000 SDK，只取出需要的檔案放進遊戲。

想手動處理：用 7-Zip 打開這個 SDK，取出 Program Files/mfc/lib/arm/mfcce300.dll 與 olece300.dll（MIPS、SH3 版遊戲改用 mips、sh3 資料夾），再和遊戲一起匯入。

一次匯入多個檔案

按「匯入遊戲」時可以同時選好幾個檔案，例如遊戲的 .cab 加上 mfcce300.dll，或遊戲本體加上資料檔。本站會自動把它們組成一個遊戲包，不用自己壓縮。

備份與搬移存檔

進度每 10 秒自動保存在瀏覽器裡。在遊戲庫按遊戲旁的「⋯ › 下載存檔」得到一個 .zip；到另一台電腦、Windows 版或 Android 版，用「⋯ › 匯入存檔」就能接著玩。

在手機或平板上玩

用手機瀏覽器打開本站就能玩，畫面下方會出現方向鍵和 A／B／C 按鈕；橫放時按鍵會移到兩側。想要離線玩，可以安裝 Android 版。

遊戲打不開怎麼辦

畫面會用白話說明原因與下一步，例如「這是桌面程式」「這是 .NET 程式」。多數下載檔有好幾個處理器版本，本站會自動挑選。也可以先查 相容性清單，看看這個軟體的測試結果。

為什麼好用

不是完整模擬整台機器，而是用 Rust 重新實作 Windows CE，所以開得快、不需要 ROM。

三種處理器ARM（iPAQ、Axim）、MIPS（Casio Cassiopeia）、SH3（HP Jornada）的版本都能玩。
看得懂下載檔安裝程式、自解壓檔、藏在裡面的 CAB、1999 年的壓縮格式，都能自動拆出遊戲。
存檔到處通用同一個存檔 zip 可以在網頁、Windows、Android 之間搬來搬去。
實測上千個軟體archive.org 上 1,443 個下載檔都測過，相容性清單寫明每個的結果。

常見問題

遇到問題先看這裡。

需要 Pocket PC 的 ROM 或系統檔嗎？

不需要。大多數遊戲直接就能玩。使用 MFC 的程式需要 mfcce300.dll：遊戲畫面會出現「自動取得 MFC」按鈕，本站會從 archive.org 上微軟的 Pocket PC 2000 SDK 取出它。也可以手動用 7-Zip 打開 SDK，取出 Program Files/mfc/lib/arm/mfcce300.dll，和遊戲一起匯入。

遊戲和存檔放在哪裡？會上傳嗎？

都只存在這個瀏覽器（IndexedDB），不會上傳到任何伺服器。清除網站資料會一併刪除，請先用「⋯ › 下載存檔」備份。

為什麼有的遊戲不能玩？

模擬器還沒實作所有 Windows CE 功能。.NET 程式、x86 版本和部分安裝程式目前不支援。相容性清單列出每個測過的軟體與原因。

可以在電腦或手機上離線玩嗎？

可以下載 Windows 版與 Android 版，功能與存檔格式和網頁版相同。

可以同時開兩個分頁嗎？

不行。兩個分頁會互相覆蓋進度，所以第二個分頁會停在提示畫面。

遊戲包格式

直接匯入從網路下載的檔案即可。看不懂的檔案，模擬器會依知識庫往裡面找出遊戲，絕不會執行下載的程式。

可以匯入

  • Pocket PC 的 .cab
  • 最上層放一個 .cab 的 .zip，可以附加其他檔案（例如 mfcce300.dll）
  • 遊戲安裝後資料夾的 .zip，例如 quake/PocketQuake.exe
  • ARM 版的 .exe、.rar
  • 桌面安裝程式（setup.exe，包括 InstallShield、Wise 製作的）或每種處理器各一個 CAB 的下載檔：會自動挑出 ARM 版

遊戲需要的系統檔案

使用 MFC 的遊戲需要 Pocket PC 內建的 mfcce300.dll（有些還需要 olece300.dll），模擬器不附帶。請把你自己裝置上的副本放進 .zip，和 .cab 放在同一層。缺少時，開始遊戲前會提示。

無法匯入

  • .NET Compact Framework 程式
  • 使用浮點指令的 SH4 程式，以及 x86 版本
  • 桌面版 Windows 遊戲與它的 data1.cab

存檔

存檔 .zip 包含遊戲的 saves/ 資料夾與 pockethle-registry.dat，Windows、Android 與網頁版通用。
放開即可匯入.zip、.cab、.exe，可一次多個檔案
